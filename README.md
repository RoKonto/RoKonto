# Hi, I'm RoKonto

I work on **prompt engineering, LLM evaluation, and
privacy and security tooling** that runs locally.

## What I'm building

- **[local-pii-redactor](https://github.com/RoKonto/local-pii-redactor)**: masks personal data on your own
  machine before text goes to a cloud AI, with a built-in precision/recall evaluation harness.
  Python, optional local LLM via Ollama. In active development; roadmap and issues are in the repo.

## What I'm interested in

- Measuring LLM behavior with repeatable evals
- Privacy-preserving workflows: local models, minimal data sharing
- Practical security for individuals and small teams
- Working with AI coding assistants in the terminal while keeping ownership and review of the code
